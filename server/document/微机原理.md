# 第一章：基础知识

## 1. 计算机发展与组成

- ENIAC；电子管 → 晶体管 → 集成电路 → 大规模及超大规模集成电路。
- 微处理器：CPU，负责运算和控制。
- 微型计算机：CPU、存储器、I/O 接口、系统总线。
- 微型计算机系统：再加外设和软件等。
- 总线：地址总线 AB、数据总线 DB、控制总线 CB。

## 2. ASCII 码

- 正确名称是 ASCII，不是 ASCLL。
- '0'＝30H，'A'＝41H，'a'＝61H；对应大小写字母相差 20H。
- Z 与 a 中间依次是：左方括号、反斜杠、右方括号、脱字符、下划线、反引号。
- 数值 5＝05H，字符 '5'＝35H；数字字符转数值减 30H，0～9 的数值转字符加 30H。

## 3. 有符号数、无符号数与补码

- 寄存器和内存只保存二进制位，没有自带的有符号标签；含义由程序决定。
- 8 位无符号数范围：0～255；8 位有符号补码范围：−128～127。
- 同一编码 AAH＝10101010B：按无符号数解释为 170，按有符号补码解释为 −86。
- 正数的原码、反码、补码相同；负数由原码转补码：符号位不变，其余位取反，再加 1。
- 已知补码，求相反数的补码：全部位取反，加 1。最小负数的相反数无法在原位宽内表示。
- ADD、SUB 不需要先区分符号，同时设置 CF 和 OF；程序根据数据含义选择检查哪个标志。
- 有无符号数都可以存储和运算，不是“无符号只用于存储”。

## 4. CF 与 OF

- CF：无符号加法看最高位向外进位；无符号减法看向整个位宽之外的借位。
- SUB A,B：把原始位串当无符号数比较，A＜B 则 CF＝1，否则 CF＝0。中间位借位不代表最终 CF＝1。
- OF：有符号数学结果超出该位宽的补码范围。
- 加法：同号相加，结果与原操作数异号，OF＝1；异号相加不溢出。
- 减法：两数异号相减，结果与被减数异号，OF＝1；同号相减不溢出。
- 减法可用“被减数＋减数全部位取反＋1”实现；该内部加法的最高位进位不能直接当作 SUB 的 CF。

| 8 位运算 | 有符号解释 | 低 8 位结果 | CF | OF |
|---|---|---|---|---|
| 7FH＋01H | 127＋1，超范围 | 80H | 0 | 1 |
| AAH＋7CH | −86＋124＝38 | 26H | 1 | 0 |
| AAH−7CH | −86−124＝−210，超范围 | 2EH | 0 | 1 |
| AAH−8CH | −86−(−116)＝30 | 1EH | 0 | 0 |

注意：7CH＝01111100B；01111010B 是 7AH。课件 AAH−7CH＝2DH 有笔误，正确低 8 位是 2EH。

# 第二章：8086 结构、寻址与指令

## 1. BIU 与 EU

- BIU（总线接口部件）：取指令、形成物理地址、访问内存与 I/O。包含 CS、DS、SS、ES、IP、地址加法器、指令队列等。
- EU（执行部件）：译码和执行指令。包含 ALU、AX/BX/CX/DX、SP/BP/SI/DI、FLAGS 及控制电路等。
- 8086：16 位 CPU，20 位地址总线，最多寻址 1 MB；每个逻辑段最大 64 KB。

## 2. 寄存器：下次重点回顾

| 寄存器 | 主要用途 |
|---|---|
| AX | 累加器；可拆成 AH、AL |
| BX | 基址寄存器；可拆成 BH、BL |
| CX | 循环、串操作计数；CL 可保存移位次数 |
| DX | 双字数据高位，或 I/O 端口地址 |
| SP | 栈顶的偏移地址；与 SS 配合 |
| BP | 基址指针，常用于访问堆栈数据；内存寻址含 BP 时默认用 SS |
| SI | 源变址；串操作源地址通常为 DS:SI |
| DI | 目的变址；串操作目的地址为 ES:DI |
| CS:IP | 代码段及下一条指令的偏移地址 |
| DS | 默认数据段 |
| SS | 堆栈段 |
| ES | 附加段 |

- 按课件分类，SP、BP、SI、DI 称专用寄存器；它们不是 EA。
- 8086 没有名为 DP 的寄存器；DX 也不是普通内存间接寻址寄存器。

## 3. EA 与寻址：下次重点回顾

- EA（Effective Address）：有效地址，即内存操作数的段内偏移地址，不是寄存器。
- 8086 实模式物理地址＝段寄存器值×10H＋EA。
- 立即寻址：MOV AX,1234H，1234H 就是数据。
- 寄存器寻址：MOV AX,BX，数据在 BX 中。
- 内存直接寻址：MOV AX,[1234H]，EA＝1234H，读取该位置的数据。
- 寄存器间接寻址：MOV AX,[BX]，BX 的内容是 EA，不是要读取的数据。
- 普通内存寻址可使用 BX、BP、SI、DI；不能用 [AX]、[CX]、[DX]、[SP]。
- 两个地址寄存器组合为 BX/BP＋SI/DI，可再加位移量，例如 [BX+SI+10H]。
- 含 BP 默认使用 SS，其余上述普通数据寻址默认使用 DS，可用段超越改变。
- LEA 取得 EA，不读取该地址中的数据；MOV 从内存读取的是内容。
- 数据地址与数据含义不同：一个内存单元的内容可以按有符号、无符号或其他编码解释。

## 4. 已学习的指令

### MOV

- 复制数据，源、目的位宽需匹配；不能直接内存到内存。
- 立即数不能直接送段寄存器，常用 MOV AX,DATA / MOV DS,AX。

### PUSH / POP

- 8086 按字操作，堆栈后进先出。
- PUSH：SP 先减 2，再存入；POP：先取出，再使 SP 加 2。

### XCHG

- 可交换寄存器与寄存器，或寄存器与内存。
- “不能均为内存”是指不能两个操作数都是内存，不是禁止出现内存操作数。
- XCHG [2530],CX 合法；CX 是寄存器，且决定交换的是 16 位字。

### IN / OUT

- IN：I/O 端口 → AL/AX；OUT：AL/AX → I/O 端口。
- AL/AX 保存数据；DX 保存端口号，不能随意互换角色。
- IN AL,50H：从 50H 端口读一个字节到 AL，不是把 50H 放进 AL。
- IN AX,DX：从 DX 指定端口读取一个字到 AX。
- OUT DX,AL：把 AL 的字节写到 DX 指定端口。
- 立即端口号范围 00H～FFH；更大的端口号必须放入 DX。
- MOV AL,[50H] 读内存；IN AL,50H 读 I/O 端口。8086 中两者是独立地址空间。
- 端口读取可能触发设备动作，不一定像普通内存读取一样没有副作用。
